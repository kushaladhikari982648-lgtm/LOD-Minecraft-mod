# PocketLOD v0.4.0 — Minecraft 1.20.1

## Install

Download **pocketlod-0.4.0.jar** into your launcher's `mods` folder, alongside
**Fabric API 0.92.2+1.20.1**. Use **Minecraft Java 1.20.1**, **Fabric Loader 0.16.14**,
and **Java 17**. The `-sources.jar` is for developers, not installation.

Open **Video Settings → PocketLOD...**, press **F8**, or use `/pocketlod`.
The default preset is **4 GB Mobile**: 32-chunk LOD radius, HIGH graphics, bounded
cache/quad budgets. Singleplayer distant generation requires confirmation and is
off by default. Back up your save before enabling generation of real world chunks.

## Included

- Median-based terrain LOD pyramid and fast chunk-section sampling.
- Greedy axis-aligned voxel roofs/cliffs, surface lips, directional shading and AO.
- Circular near-field overlap, depth bias, budgeted recentering and custom shaders.
- Single-flight SURFACE/FEATURES generation with cancellable tickets.
- Primitive caches, checksummed disk persistence and dirty-tracked autosaves.
- Exact radius controls, Mobile/Low-End PC/Ultra presets, F8 and client commands.

## Validation and limitations

The full pinned Fabric/Loom build and core regression runner pass on GitHub CI.
The release JAR is additionally checked for Java 17 bytecode, metadata, mixin/refmap
resources and shader resources. `SHA256SUMS` contains hashes of both JARs.

**Experimental gameplay status:** real Minecraft launch, shader compilation,
mobile GL drivers, MJ Launcher/Zalith, low-FPS visual behavior and memory/FPS
benchmarks have not yet been validated. This is not a promise of glitch-free
rendering or compatibility with every launcher. Report failures with device,
launcher, runtime, renderer and logs.

Multiplayer is capture-only; unknown distant terrain appears only after exploration
or singleplayer generation. Iris shader packs pause LOD rendering. Terrain has no
full-resolution block models, caves or entities. No Minecraft 1.16.5 port is included.

See `docs/VALIDATION.md` for the outstanding gameplay checklist.
